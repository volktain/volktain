### 📌 Featured Projects

#### 🛡️ [Linux Log Threat Sentinel](https://github.com/volktain/threat-intel-sentinel)
*Python-based Threat Intelligence and log analysis tool.*
- Monitors SSH authentication attempts in Linux (`/var/log/auth.log`) and extracts suspicious IPs using Regex.
- Cross-references IP addresses in real-time against the public **Feodo Tracker** API to detect active Botnet C2 servers (Emotet, QakBot).
- Fully containerized with **Docker** and configured for continuous background execution via **Systemd**.

#### 🌐 [TCP Port Scanner](https://github.com/volktain/port-scanner)
*Low-level network port scanning tool.*
- Built in Python using the native `socket` library (`connect_ex`) for real TCP connectivity verification.
- Features timeout control, open port detection, and attack surface analysis logic.
